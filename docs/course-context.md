# 课程项目

这个 PJ 是我在复旦大学《数据结构 H》课程中完成的向量检索项目，题目于 2025 年 11 月 5 日发布。

## 任务

我需要为给定的向量底库建立索引，为每个查询找到 L2 距离最近的 10 个底库向量，并返回它们的 ID。优化目标是在满足召回率要求的前提下，尽量降低平均查询时延。

课程使用 SIFT 和 GloVe 两组数据，要求 **Recall@10 ≥ 0.99**，同时记录索引构建时间。

## 提交接口

```cpp
class Solution {
public:
    void build(int dim, const std::vector<float>& base);
    void search(const std::vector<float>& query, int* res);
};
```

- `build`：输入维度和按行展开的底库，完成索引构建。
- `search`：输入查询向量，向长度为 10 的结果数组写入检索 ID。
- 返回的 ID 对应底库中从 0 开始的向量位置。

## 评价指标

| 指标 | 含义 |
| --- | --- |
| Recall@10 | 返回的 10 个 ID 与真实 top-10 ID 的交集占比，再对查询取平均 |
| 平均查询时延 | 所有查询耗时的平均值 |
| 索引构建时延 | `build` 的运行耗时 |

实验中，我还记录了中位数查询时延和平均距离计算次数，用来分析搜索扩展规模及实现层优化的效果。

## 我的实现

我选择了 HNSW 图索引，并围绕构建顺序、图后处理和查询早停做优化，结合 SQ16、AVX2 和并行建图改善执行效率。
