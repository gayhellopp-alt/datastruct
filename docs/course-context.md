# 课程项目要求摘要

来源：复旦大学《数据结构 H》课程 PJ 说明材料，发布日期为 2025 年 11 月 5 日。本文为便于理解项目而整理的摘要；原始课件在本地材料归档中保留。

## 任务

给定向量底库和查询向量，设计向量索引，为每个查询返回相似度最高的 10 个底库向量 ID。任务以 L2 距离衡量相似性，目标是在满足检索精度约束的前提下降低平均查询时延。

课件列出的精度约束为 **Recall@10 ≥ 0.99**，同时记录索引构建时间。课程涉及 SIFT 和 GloVe 两组数据。

## 提交接口

```cpp
class Solution {
public:
    void build(int dim, const std::vector<float>& base);
    void search(const std::vector<float>& query, int* res);
};
```

- `build`：输入维度和按行展开的底库，完成索引构建。
- `search`：输入查询向量，向调用方提供的长度为 10 的数组写入检索 ID。
- 返回的 ID 对应底库中从 0 开始的向量位置。

## 评价指标

| 指标 | 含义 |
| --- | --- |
| Recall@10 | 返回的 10 个 ID 与真实 top-10 ID 的交集占比，再对查询取平均 |
| 平均查询时延 | 所有查询耗时的平均值 |
| 索引构建时延 | `build` 的运行耗时 |

最终报告还增加了中位数查询时延和平均距离计算次数，用于分析查询过程中的计算和访存成本。
